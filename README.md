# 雪山缆车救援行动

一个纯前端 3D 操作型救援游戏，使用 React、Vite、TypeScript、React Three Fiber 和 Three.js 构建，不包含后端服务。

## 操作

- `WASD` / 方向键：移动救援员
- `Shift`：冲刺，消耗体力
- `Q` 对应按钮：打入冰镐锚点
- `E` 对应按钮：靠近受困者后连接救援绳
- `R` 对应按钮：收紧救援绳
- `Esc` 对应按钮：暂停 / 继续行动
- 拖拽场景：旋转观察视角
- 滚轮：缩放

## 任务回放

- 任务结束（成功或失败）后，HUD 右侧"任务回放"面板自动生成本局记录
- 记录内容：移动、冲刺、建立锚点、收紧绳索、暂停、成功与失败等关键事件，以及逐帧位置与状态
- 点击播放进入回放模式：任务模拟冻结，3D 场景与状态面板同步到时间线选定时刻
- 支持播放 / 暂停，点击或拖动时间线定位（也支持 ←/→、Home/End 键微调）
- 任务进行中显示"暂无回放记录"；回放结束会按成功 / 失败给出提示，可重新播放或退出回放
- 点击"重新开始任务"会清空上一局的全部回放记录

## 启动

```bash
npm install
npm run dev
```

当前为单机基础版本，游戏状态保存在内存中。后续可扩展攀爬动画、绳索物理、雪崩事件、体力恢复点、关卡编辑器和本地存档。
